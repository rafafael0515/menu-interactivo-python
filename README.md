# 🧾 Menú Interactivo en Python

Aplicación de consola desarrollada en Python que permite gestionar usuarios 
mediante un sistema CRUD (Crear, Leer, Actualizar, Eliminar).

---

## 🚀 Funcionalidades

* ✅ Registrar usuarios
* 📋 Ver lista de usuarios
* 🔍 Buscar usuarios
* ✏️ Editar usuarios
* ❌ Eliminar usuarios
* 💾 Persistencia de datos en archivo JSON

---

## 🛠️ Tecnologías utilizadas

* Python 3
* Manejo de archivos JSON
* Programación estructurada

---

## 📂 Estructura del proyecto

```
MENU INTERACTIVO/
├── main.py
├── usuarios.json
└── .gitignore
```

---

## ▶️ Cómo ejecutar el proyecto

1. Abre la terminal en la carpeta del proyecto
2. Ejecuta el siguiente comando:

```bash
python main.py
```
